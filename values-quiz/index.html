HOW IT WORKS

一份測驗，兩種角度

STEP 01各自填答

打開同一份 HTML，輸入自己的名字，完成 15 大面向共 75 題。請依個人想法回答。

STEP 02各自下載

每題都答完後下載 JSON。若共用裝置，第一人下載後點「清空重新填寫」。

STEP 03比較與討論

在「雙人比較」匯入兩份 JSON 查看簡易結果；也可把兩份 JSON 傳給 ChatGPT 深度分析。

如何分享給另一個人？

把這份 HTML 檔傳給對方即可離線開啟。HTML 檔本身不是公開網址；若要產生可分享連結，需部署到 GitHub Pages、Netlify 或其他靜態網頁服務。

這份測驗會上傳個資嗎？

不會。題目與比較功能都在你的瀏覽器執行；若瀏覽器允許，正在填寫的資料會暫存在本機瀏覽器，直到你清空。匯出的 JSON 只會在你主動分享時離開裝置。

分數怎麼算？

每題的差距為兩人分數相差的絕對值（0～4）。接近度 =（1 − 所有題目的平均差距 ÷ 4）× 100%。100% 代表 75 題選擇完全相同，不等於心理學上「100% 相容」。每面向則以該面向五題計算。

這是心理診斷或正式量表嗎？

不是。本測驗為對話與自我探索設計，未經信效度驗證。單一題目的答案可能受語境與當下狀態影響，尤其第 3 分可能代表中立、猶豫或視情況而定。請把差異作為討論起點，而不是判斷誰對誰錯。
